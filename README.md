# 秋叶孤儿院调查录 · 开场导入

## 当前加载方式

点击封面即可进入，不需要等待119项资源全部完成。图片和音乐分队列在后台提前加载；正在播放的音乐可直接流式读取。资源暂时失败会自动重试，不会弹出全量加载失败提示或锁住入口。

当前版本包含开场原文、需确认的声明、PP 模拟登录、五位联系人的聊天记录，以及六个相册。“光辉岁月”需要回答访问问题，目前包含两张照片和对应配文、评论；“本天才画展”为公开相册，包含五幅画作及对应简介、配文、评论；“猫猫观察日记”包含四张猫咪照片；“和爸爸”为公开相册，包含三张照片及对应简介、配文、评论。博客包含公开开张日志和密码访问日志。邮箱暂保留入口。

## 打开游戏

直接双击 `index.html`，用浏览器打开即可。无需安装依赖，无需联网。

用 Visual Studio Code 打开本文件夹即可编辑；也可以使用 Live Server 预览。

手机和平板使用自适应布局。需要在设备浏览器中打开完整项目，或通过电脑的本地预览服务访问；只传一个 HTML 文件会缺少图片和样式。

## 修改内容

- `story.js`：开场文字、声明原文。
- `chats.js`：按联系人和日期分组的聊天原文。
- `albums.js`：相册名称、访问问题、照片、配文及评论。
- `index.html`：开场与登录界面，账号与预填密码。
- `styles.css`：布局、配色、电脑/平板/手机适配。
- `modern-ui.css`：现代 PP 界面的配色、导航与消息层次微调。
- `app.js`：页面切换、模拟登录、聊天浏览和相册访问。
- `accounts.js`：当前账号、旧账号、别名与本地剧情密码的集中配置。
- `second-play.js`、`second-play.css`：旧账号登录演出、声音与2008聊天窗口。
- `second-play-data.js`：V4 演出的八日正式台词与最后一句。
- `assets/*.webp`：网页使用的压缩头像。
- `assets/photos/`：相册照片的缩略图、手机图与大图。
- `assets/audio/`：二周目演出使用的《秋风》音轨。

相册的解锁状态保存在当前浏览器。照片详情显示完整照片，保留边缘文字；图片按显示尺寸选择版本，图片和音乐在后台按优先级提前加载，进入游戏不等待全量资源。查看照片时，评论列表独立滚动，照片保持固定。

“隐藏相册”只是相册名称，与其他相册一起显示。“光辉岁月”和“隐藏相册”均设有访问问题，列表封面始终显示锁定图标，回答正确后才能进入查看照片。

每次进入登录页都会显示已记住的账号和“切换账号”，开局与退出登录后的界面保持一致。初次默认选中“忧郁小猫猫”，预填账号与密码均为只读；点击“切换账号”即可手动输入其他账号。登录不连接任何账号服务、不发送账号信息。登录后进入本地聊天记录界面。

2008 年界面保留早期即时通信软件的蓝色渐变窗框、工具栏、白底聊天记录和个人形象。演出与结尾均不显示电脑桌面、草地、任务栏或额外好友列表。手机优先保留聊天内容和输入区。

演出先呈现现代账号登录，以及2008年旧账号被异地登录挤下线。随后按8月18日至25日回放83条正式消息。复古提示音伴随消息出现，背景音乐从首日消息开始，最后一条等待消息后收束。次日后半开始出现外围消息框。卡片错落叠放，部分卡片压住中央窗框边缘。

安静停顿后，中央窗口显示“2008-08-25 18:40 你也不要我了吗？”。随后日历从8月25日逐张翻回8月18日，中央窗内的记录逐日向上滚动，外围小窗随每次翻日从外到内分批淡出。偏好减少动态效果时，日期和记录直接切换。

翻页落定后只留下干净的2008年聊天窗口与8月18日记录，8月19日至25日的未来消息不会保留。玩家新发消息的日期固定为 `2008-08-18`，时、分、秒取每次发送时的设备本地真实时间；窗口底部时钟按真实时间更新，日期始终停在8月18日。演出支持静音、跳过、退出与重复进入。当前版本不生成后续剧情或自动回复，所有操作均在本地模拟。
